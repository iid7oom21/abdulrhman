# RAVEN — معاينة «الاسم المحذوف»

هذه معاينة تقنية في الملفات الأصلية، وليست القصة المستعادة أو نموذج صفحة الشخصية المرفق المفقود.
الإفادات الأصلية غير مكتملة، لذلك لا تختلق المحاكاة شهادة أو حضور اللاعب قبل الواقعة.
تظل واجهة الشخصيتين وتصميمها؛ رد المحاكاة يصرح بحدود المصدر ولا ينشئ دليلًا.

```bash
npm test --prefix server/ai-dialogue
npm start --prefix server/ai-dialogue
```

Node.js حديث يدعم الاختبارات المدمجة (اختُبر بـ24.19.0)، دون حزم تشغيل خارجية.
المنفذ من `PORT` وافتراضيًا 10000. خادم المعاينة مستقل عن خادم محاكاة الرصيد
في `server/src/index.js`؛ لا توجد خدمة مدفوعة أو مزود نموذج أو بوابة دفع في مسار المعاينة.

اختبارات المتصفح اختيارية وتتطلب Playwright وChromium:

```bash
CHROMIUM_PATH=/usr/bin/chromium node --test server/ai-dialogue/tests/browser.cjs
```

إذا لم يتوفر Playwright يمكن تثبيته في مساحة اختبار منفصلة؛ لا تحتاجه لتشغيل المعاينة.
`SCREENSHOT_DIR` مجلد موجود اختياري لحفظ لقطات 320/375/390.

## عقد الحفظ والمتابعة

- الخادم يصدر ملف ارتباط HttpOnly/SameSite=Strict لجلسة متصفح مجهولة. ليست هوية حساب موثقة.
- طلب `POST /api/dialogue` يحتاج JSON من `requestId, characterId, message`.
  المعرف يجب أن يبقى نفسه للعملية. لا تقبل الواجهة إرسالًا آخر للشخصية حتى تُحسم العملية.
- إعادة نفس المعرف ونفس المحتوى تستعيد العملية، ومحتوى مختلف ينتج 409.
  البصمة SHA-256 لكامل المحتوى بدل اختصار بادئته. التنفيذ الحالي محاكاة متزامنة فقط.
- `GET /api/operations/:id` يقرأ العملية الأصلية دون توليد أو تحويل الخطأ إلى نجاح.
- `GET /api/history` يعيد سجل الجلسة فقط. لا يعتد الخادم بـownerId أو owner من العميل.
- لا يعتد الخادم بـsharedFacts من العميل؛ لا يوجد محرك أحداث موثوق لمشاركة مواد القصة هنا.
- السجل في ذاكرة عملية Node، وليس حفظًا دائمًا. إعادة تشغيل الخادم أو فقد الجلسة يفقد الوصول إليه.
- تستخدم الصفحة المفتاح المحلي الوحيد `raven_deleted_name_preview_v2` للعمليات والمسودات.
  لا تمسح المفاتيح القديمة أو تفضيلات الموسيقى أو بيانات التطبيقات الأخرى. يبقى المحتوى غير المقروء كما هو.
- المتابعة GET فقط؛ لا يعاد POST تلقائيًا بعد انقطاع الشبكة أو توقف الانتظار.
  عند 404/401 بعد فقد الخادم تبقى العملية غير محسومة ومحفوظة محليًا إن أمكن، ولا يدّعى إلغاؤها.
- الرد المعلوم دون إقرار مرتبط بمعرفه ونوع التخزين يبقى ظاهرًا بحفظ غير مؤكد؛ لا يُعاد توليده.
- فشل التخزين المحلي يبقي الرد والمسودة في ذاكرة الصفحة ويظهر عدم تأكد الحفظ المحلي.
- تحميل السجل يدمج بالمعرف والشخصية، ويحافظ على الأسئلة المعلقة والردود غير المؤكدة.
- «مسح العرض» يخفي العرض فقط؛ تحميل السجل يعيده ولا يمسح التخزين.
