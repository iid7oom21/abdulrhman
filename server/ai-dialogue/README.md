# RAVEN AI Dialogue Preview (Jonas & Claire)

معاينة محادثة AI نصية حرة مع عزل معرفة لكل شخصية.

المرجع: BELHAQAK-GUEST-WITNESS-20261030

## التشغيل

```bash
cd server/ai-dialogue
npm test
```

## الوضع

- وضع المحاكاة مفعّل افتراضيًا (لا يحتاج مفتاح API).
- المفتاح يُقرأ من بيئة الخادم فقط عند التفعيل الحقيقي.
- كل شخصية لها سياق معرفة مستقل.
- معرّف طلب المحادثة منفصل عن مفتاح مشاركة الدليل.
- الرد يُحفظ قبل التسليم.

## حالات القبول

الاختبارات في `tests/` تغطي TC-A01 إلى TC-A08 في وضع المحاكاة.
اختبار المزود الحقيقي: غير منفذ (لا يوجد مفتاح).

## العوائق

- لا يوجد مفتاح API في البيئة الحالية.
- لم يُشغّل خادم حي أو معاينة متصفح في هذا التسليم.
