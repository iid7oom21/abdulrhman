# RAVEN AI Dialogue Preview (Jonas & Claire)

معاينة محادثة نصية محاكاة ليوناس وكلير.

المرجع: BELHAQAK-GUEST-WITNESS-20261030

## التشغيل المحلي

```bash
cd server/ai-dialogue
npm test
npm start
```

الخادم يستمع على `0.0.0.0` والمنفذ من `process.env.PORT` (افتراضي 10000).

## النشر على Render

- أمر البناء: `npm install`
- أمر التشغيل: `npm start`
- الجذر: جذر المستودع

الردود محاكاة. الحفظ في ذاكرة الخادم (يُفقد عند إعادة التشغيل).

## حدود الأمان والجلسة

- تُربط المحادثات بملف تعريف ارتباط موقّع يصدره الخادم، مع `HttpOnly` و`SameSite=Strict`. حقول المالك المرسلة من العميل لا تحدد صلاحية الوصول.
- الجلسة والسجل مؤقتان، وتبدؤان من جديد بعد إعادة تشغيل الخادم. معرّفات المالك القديمة في `localStorage` لا تُستخدم لنقل السجل لأنها لا تثبت هوية صاحبه.
- الطلبات إلى `/api/dialogue` تستخدم `Content-Type: application/json`؛ الحد الأقصى للجسم 16 KiB، وللرسالة 4,000 حرف.
- للنشر خلف وكيل HTTPS، اضبط `COOKIE_SECURE=true` مع تقييد معدّل الطلبات وسياسة لحذف السجلات القديمة.
- نتائج المراجعة المحلية في [تقرير الأمان](../../docs/security-review.md).
