# RAVEN — خادم معاينة الحوار

معاينة مستقلة عن افتتاح «الورقة» وعن محاكاة GitHub Pages. اللاعب مرمّم سجلات وصل بعد الواقعة. الإفادات الأصلية غير متاحة؛ لا يملأها النموذج.

**القضية المكتوبة:** أضيف مسار مستقل `/api/case/*` لعرض حزمة قصة خاصة مع تقدم محفوظ ودفتر وتقارير. هذه ليست معرفة حرة لنموذج الحوار. الحزمة تبقى خارج Git والجذر العام، وواجهة اللعب تحت `/raven/deleted-name/play/`. انظر [التشغيل الخاص](../../docs/CASE-LOCAL.md) لتشغيلها دون مفتاح أو اتصال مدفوع. غياب الحزمة يعطّل مسار القصة بوضوح؛ لا تتحول المحاكاة إلى قضية مكتملة.

## تشغيل محلي

```bash
npm start --prefix server/ai-dialogue
npm test --prefix server/ai-dialogue
CHROMIUM_PATH=/usr/bin/chromium node --test server/ai-dialogue/tests/browser.cjs server/ai-dialogue/tests/materials-browser.cjs server/ai-dialogue/tests/reliability-browser.cjs
```

Node 24، دون اعتماديات تشغيل خارجية. Playwright وChromium لازمان لاختبارات المتصفح فقط.
المنفذ `PORT` وافتراضيًا 10000؛ العنوان `HOST` وافتراضيًا `127.0.0.1`.
`/healthz` لفحص التشغيل دون إنشاء جلسات. `/api/config` يوضح الوضع والحفظ دون أسرار.
الخادم يخدم واجهته من الأصل نفسه؛ لا يُربط بصفحة GitHub Pages أو محاكاة الرصيد تلقائيًا.

## تشغيل الموقع ومعاينة الخادم من عنوان محلي واحد

يمكن ضبط `RAVEN_SITE_ROOT` إلى **مسار مطلق لنسخة الموقع العام المراجعة**؛ برمجيًا الخيار `siteRoot` في `createPreviewServer`. يظل الربط معطّلًا افتراضيًا. مثال محلي من جذر مستودع الخادم:

```bash
RAVEN_AI_PROVIDER=simulation RAVEN_SITE_ROOT=/absolute/path/to/public-site npm start --prefix server/ai-dialogue
```

افتح `http://127.0.0.1:10000/raven/` أو `/raven/deleted-name/`. الرابط الموجود إلى `/raven/dialogue/` يفتح **واجهة الخادم الحالية** ويصدر كوكي الجلسة نفسه؛ لا يحتاج `?mode=server` ولا يحمل `local-api.js`. يبقى `/` و`/index.html` لواجهة الخادم المستقلة، وعقود `/api/*` و`/texts/raven-texts.js` كما هي. يستطيع إطار الموقع عرض معاينة الخادم من الأصل نفسه؛ واجهة الخادم المستقلة وواجهات JSON تحتفظ بمنع التأطير.

واجهة الحوار الخادمية الحالية بالعربية. مع `?lang=en` يظهر تنبيه إنجليزي واضح بهذا القيد ويحافظ رابط الرجوع على لغة الافتتاح. هذا ليس تعريبًا/ترجمة كاملة جديدة لواجهة الخادم. واجهة المحاكاة المنشورة على GitHub Pages تبقى مستقلة.

الحوار يقرأ `/api/config` لتوضيح المزوّد والحفظ، ويستعمل `saveStatus` عند تأكيد النتائج. مصدر معرفة الشخصيات الأصلية يبقى غير متاح (`sourceKnowledgeAvailable:false`). اختيارات الافتتاح لا تنتقل إلى الخادم، ولا تُستورد مواد أو عمليات المحاكاة المحلية تلقائيًا. تشغيل الموقع من هذا الخادم لا يفعّل نموذجًا أو بوابة دفع ولا ينشر خدمة خارجية.

تستخدم الصفحة المركّبة مفتاحي متصفح مستقلين: `raven_deleted_name_hosted_server_preview_v2` و`raven_deleted_name_hosted_server_material_actions_v1`. لا تقرأ أو تستبدل مفاتيح المحاكاة القديمة، وتبقى مفاتيح واجهة `/` المستقلة كما كانت. بيانات الخادم نفسها تبقى في الجلسة وملف الحفظ القائمين.

تُخدم ملفات تشغيل محددة بالاسم في `src/site-mount.js`؛ لا عرض للمجلدات ولا سماح عام حسب امتداد الملف. ملفات المؤلف والتقارير والنسخ والبيئة وGit غير متاحة. تُرفض المسارات غير الطبيعية والروابط الرمزية، حتى داخل الجذر؛ يلزم تصدير ملفات فعلية. تبقى الملفات الأصلية كما هي. تدعم الوسائط GET/HEAD ونطاق بايت واحد، وتبقى قائمة الموسيقى 01–13. سياسة CSP الخاصة بصفحات الموقع تسمح بإطارات من الأصل نفسه وبمصادر الوسائط والخطوط الحالية؛ لا توسّع سياسة API أو تسمح بنصوص خارجية جديدة.

اختبارات الربط: `node --test server/ai-dialogue/tests/site-mount.test.js`. تستخدم نقل مزوّد وهميًا فقط وتتحقق من جلسة فعلية، وحصر المعرفة بالمستلم، والحفظ وإعادة التشغيل ومنع تكرار الطلب، ومنع تسريب الملفات. هذا تجهيز محلي؛ لا يحل الاستضافة أو هوية الحسابات أو حدود تكلفة خدمة عامة. للإلغاء احذف `RAVEN_SITE_ROOT` وأعد تشغيل الخادم؛ لا يتغير ملف الحفظ أو الموقع العام.

اختبار المتصفح الاختياري: `CHROMIUM_PATH=/usr/bin/chromium node --test server/ai-dialogue/tests/site-mount-browser.cjs`. يتحقق من التأطير وCSP والاتصال بـAPI والحفاظ على مفاتيح المحاكاة والتفضيلات القديمة دون استيرادها.

## الحفظ

التشغيل من CLI يحفظ افتراضيًا إلى `server/ai-dialogue/.data/preview-store.json`، بصرف النظر عن مجلد تشغيل الأمر.
`RAVEN_DIALOGUE_STORAGE_PATH` يغيّر المسار. الاسم القديم `RAVEN_STORE_FILE` يعمل إن لم يحدد الاسم الجديد.
يبقى بعد إعادة التشغيل ما دام القرص نفسه موجودًا.
يضيع إذا مُسح القرص أو تغيّرت الآلة.
هذا ليس حفظ إنتاج سحابي.

الملف يحفظ الجلسات ومواد اللاعب ومشاركاته وعمليات الحوار. تُكتب نسخة مؤقتة بصلاحية 0600 وfsync ثم rename. شغّل عملية واحدة على الملف؛ ليس مخزنًا موزعًا أو مخزنًا لعدة عمال.
تُفحص البنية كاملة قبل الاستعادة. الملف التالف، بما فيه JSON صحيح بمحتوى داخلي غير صالح، يُترك دون كتابة ويرفض الإقلاع. لا توجد إعادة ضبط تلقائية للذاكرة عند الاستعادة.
القراءات لا تُنشئ نتيجة ولا تولّد ردًا. آخر نشاط للجلسات يُحفظ أيضًا بنقطة تحقق مستقلة كل دقيقة.
جلسة خاملة 6 ساعات تنتهي؛ الحد 100 جلسة ويُستبعد الأقل استخدامًا. وجود الملف لا يلغي هذه الحدود ولا يعيد كوكيًا حذفه المستخدم.

الاستدعاء البرمجي `createPreviewServer()` يستخدم ذاكرة العملية افتراضيًا لتظل الاختبارات معزولة؛ مرّر `storeFile` للحفظ. `npm start` يمرر مسار القرص تلقائيًا.
حقل `storage` يظل `server-memory` للتوافق. `persistence` يحدد `disk-file` أو `process-memory`، و`saveStatus` يحدد `confirmed` أو `memory` أو `unconfirmed`.
إذا وصل الرد وفشلت كتابة الملف، يبقى الرد معلومًا في الذاكرة ويظهر حفظ غير مؤكد. الاستعلام أو replay لا يعيد توليده. نقطة تحقق ناجحة لاحقة قد تحفظه؛ فقد العملية قبلها يفقد النتيجة غير المكتوبة.

## OpenAI الاختياري

دون إعداد مزوّد أو مفتاح قديم يعمل الوضع الافتراضي `simulation`. ضبط `RAVEN_AI_PROVIDER=simulation` صراحةً يمنع أي اتصال بمزوّد حتى مع وجود مفتاح في البيئة. للتفعيل بعد ضبط بيئة الخادم:

- `RAVEN_AI_PROVIDER=openai`
- `OPENAI_API_KEY` في مخزن أسرار بيئة التشغيل، وليس في المتصفح أو Git.
- `RAVEN_OPENAI_MODEL=gpt-5.2` (الافتراضي، قابل للتبديل إلى نموذج يدعم Responses وStructured Outputs).

ملف `.env.example` مرجع أسماء فقط؛ لا يُحمّل تلقائيًا. يمكن مع Node 24 تشغيل `node --env-file=.env src/server.js` من مجلد الخادم بعد إعداد ملف محلي غير متتبع.
هذا التنفيذ يستخدم Responses API مع `store:false` ومخطط JSON مقيد. ضبط `store:false` ليس وعدًا بعدم وجود أي احتفاظ على مستوى سياسة المزوّد.

النطاق الحالي **اختيار مواد اللاعب ذات الصلة بالسؤال** ثم عرض نصوصها بوصفها أقوالًا منسوبة إليه. ليس توليدًا حرًا لإفادات شخصيات أو قصة مكتملة.
السياق يأتي من `materials.contextFor` داخل الخادم فقط؛ يُرسل السؤال والمواد التي وصلت إلى الشخصية. لا يدخل الأصل غير المشترك أو الدافع الخاص أو معرفة شخصية أخرى. لا تُرسل المحادثة العامة أو حالة اللعبة الكاملة.
النموذج يعيد فعلًا منظمًا: `quote_materials` لاقتباس مواد مستلمة، أو `clarify` لسؤال توضيحي، أو `unavailable` لعدم توفر المصدر. الخادم يتحقق من المخطط والمعرفات ثم يركب النص؛ لا ينفذ أدوات أو أحداثًا من المخرجات. التوضيح دون معرفات يستخدم سؤالًا ثابتًا ولا يختلق اقتباسًا. أحدث تصحيح وصل إلى المستلم يصاحب أي قول سابق يختاره النموذج، حتى في سؤال التوضيح. يعمل العقد نفسه ليوناس وكلير؛ معرفة أصلية فارغة تبقى فارغة.
لا مصدر متاح يعني نص الرفض الثابت دون اتصال مدفوع. أكثر من 40 مادة أو 32000 حرف سياق يؤدي إلى رفض محافظ دون إسقاط تصحيحات سرًا. افتراضيًا حد التوازي 4، والمهلة 30 ثانية تشمل جسم الرد؛ لا إعادة محاولة تلقائية. يضبط `RAVEN_MODEL_MAX_CONCURRENT` عدد الطلبات المتزامنة في العملية (عدد صحيح من 1 إلى 16)، و`RAVEN_MODEL_TIMEOUT_MS` المهلة بالمللي ثانية (عدد صحيح من 1 إلى 120000). تنطبق الإعدادات على المزوّدين؛ غياب القيمة أو تركها فارغة يحتفظ بالافتراضي. القيم غير الصحيحة ترفض إعداد المزوّد قبل أي اتصال ولا تظهر قيمتها في الخطأ. فشل المزوّد يُسجل خطأً أو نتيجة غير محسومة، ولا يُقدّم كرد محلي ناجح من الشخصية.

اختبارات المزوّد تستعمل نقلًا وهميًا محليًا؛ لم تُجر مكالمات مدفوعة أو اختبار جودة نموذج حي. لا تنشر هذه الجلسات المجهولة للعامة مع مفتاح مدفوع دون بوابة دخول وتحديد استخدام على مستوى الحساب. فحص ذلك ونشره خارج نطاق هذه الجولة.

## توافق إعدادات النموذج السابقة

تبقى `RAVEN_MODEL_KEY` و`RAVEN_MODEL_BASE` و`RAVEN_MODEL_NAME` مدعومة: عند وجود المفتاح وعدم تحديد `RAVEN_AI_PROVIDER` تُستخدم واجهة Chat Completions المتوافقة. الافتراضي `https://api.x.ai/v1` والنموذج `grok-3` كما في التكامل السابق. يمكن اختيار `RAVEN_AI_PROVIDER=compatible` صراحةً.
العنوان يحتفظ بمسار `/v1/chat/completions`؛ كان تركيب URL السابق يحذف `/v1`. المطلوب اتصال HTTPS ودعم JSON Schema. عدم دعم المخطط يظهر فشلًا؛ لا يُستبدل برد حر أو اتصال ثانٍ تلقائيًا.
`createGroundedReply` باقٍ في `src/model.js` ويستخدم نفس تحقق المصادر ودورة العملية. `response.source` يظل `grounded-model` عند اختيار المواد، و`deterministic-fallback` عند الرفض الثابت. فشل الشبكة ليس ردًا ناجحًا ولا رفضًا معرفيًا: تبقى النتيجة غير مؤكدة. `/api/status` باقٍ للتوافق؛ `/api/config` يضيف تفاصيل الحفظ والنطاق.
لم يُختبر اتصال حي بـxAI أو OpenAI في هذه الجولة.

## عقد HTTP ودورة العملية

- كوكي `raven_preview_session` يصدره الخادم: 64 رمز hex، HttpOnly، SameSite=Strict؛ Secure مع TLS أو `RAVEN_COOKIE_SECURE=1` خلف وكيل TLS.
- `POST /api/dialogue`: `requestId, characterId, message`؛ فقط `jonas` و`claire`. `contentVersion` اختياري. `sharedFacts` إن أرسل يجب أن يكون مصفوفة فارغة. حقول سلطة العميل أو السؤال البديل مرفوضة.
- البصمة من `characterId,message,contentVersion`، مستقلة عن ترتيب مفاتيح الجسم. الوصول يُفحص قبل replay؛ تغيير المحتوى يعطي 409 والأصل باقٍ.
- تُحجز العملية ويُحفظ قصدها قبل استدعاء المزوّد. Async يرجع 202/pending؛ المتابعة GET على `/api/operations/:id`. GET لا يولّد أو يحوّل خطأ إلى نجاح.
- عملية واحدة غير محسومة لكل شخصية داخل الجلسة، حتى بين تبويبين. رفض طلب ثان يعيد `character_busy` ومعرف العملية القائمة.
- 100 عملية لكل جلسة. عند الحد يُرفض المعرف الجديد بـ429؛ تبقى المعرفات المقبولة قابلة للاسترجاع، بدل نسيانها ثم توليدها مرة ثانية.
- إعادة التشغيل أثناء طلب مزوّد تحوله إلى `unknown` دون محاولة أخرى. مهلة الشبكة أو 5xx لا تثبت إلغاء عمل المزوّد. لا استرجاع بعيد أو فشل يقيني اعتمادًا على مرور الوقت.
- الرد المكتمل يُحتفظ به عند تعثر حفظه. نتائج خاطئة أو مخططات غير مسموحة لا تعرض نص المزوّد الخام.
- POST أكبر من 40000 بايت: 413؛ JSON غير صالح: 400؛ MIME غير صحيح: 415؛ cross-site: 403.
- `GET /api/history` خاص بالجلسة؛ الدمج بالمعرف والشخصية. تحميل قديم لا يمحو رسالة جديدة أو يعرضها لشخصية أخرى.
- زر الإيقاف ينهي انتظار المتصفح فقط. 401 يطلب استعادة الجلسة. 404 عملية غير معروفة يبقي الرد والمعرف محليًا دون اختراع نتيجة.

## المواد والمشاركة

`POST /api/materials`: `id,type,text`؛ الأنواع `statement,correction,motive,private_note,report`. الخادم يضع `author=player`؛ إرساله من العميل يعطي `400 player_material_required`.
التصحيح يستخدم `originalId`، والتقرير `attachments`. الأدلة والإيصالات لا ينشئهما العميل.
`POST /api/shares`: `eventId,materialId,recipients` فقط؛ مصفوفة مستلمين لا تحتوي player. إعادة المعرف نفسه بالمحتوى نفسه لا تكرر الحدث.
200 مادة و500 مشاركة لكل جلسة. التصحيح لا يرسل أصله أو دافعه. التقرير لا ينقل إلا مرفقاته المختارة. الواجهة لا تحوّل سؤالًا إلى اتهام رسمي ولا تستنتج نية الكذب.

الواجهة تعرض النصوص بـtextContent، مع سياسة CSP. مفاتيح المتصفح `raven_deleted_name_preview_v2` و`raven_deleted_name_material_actions_v1` تحفظ المسودات والمعرفات؛ النسخ غير المتوافقة تُحفظ دون استبدال ولا تحذف بيانات تطبيقات أخرى. تنزيل المواد نسخة قراءة، وليس استيرادًا أو إيصال إيداع.

## النصوص المعتمدة

`public/texts/` يحتوي ملف ماتي الموحد وثلاثة أقسام JSON مستقلة ونفس المحتوى في حزمة المتصفح. الحزمة القديمة ذات الاسم `8songs` محفوظة حرفيًا كمرجع نصوص؛ عدد الأغاني المعتمد 13 ولا يؤخذ من اسم الحزمة أو ملاحظتها التاريخية.
`save_confirmed` لا يظهر دون إقرار لنفس العملية. `save_pending` محفوظ في الحزمة لكن لا يُخترع حدث حفظ غير موجود لعرضه.
القصة الأساسية والافتتاح المكتوب لا يحتاجان رصيدًا. لا مدفوعات في هذا المسار.

## إيقاف المزوّد والنسخ الاحتياطي — جولة ثانية 2026-11-05

RAVEN_MODEL_CALLS_ENABLED=0 يوقف النداءات الخارجية الجديدة مع إبقاء الحوار المكتوب وقراءة السجل. وللتغيير أثناء التشغيل اضبط RAVEN_RUNTIME_CONTROL_PATH إلى ملف خاص يملكه المشغّل بمحتوى `{"version":1,"providerCallsEnabled":false}`. تُقرأ قيمته عند كل توليد جديد؛ ملف مفقود أو تالف يعطل النداءات. لا endpoint لتعديل الملف من المتصفح. النداء الذي بدأ قبل الإيقاف قد يكمل؛ لا ندعي إلغاءه أو إعادة كلفته. حقول الشراء واستهلاك الاستحقاق ثابتة false، وخادم الحوار لا يقبل المال.

أوامر النسخ من مجلد server/ai-dialogue، مع وجهة جديدة غير موجودة:

```bash
node scripts/backup.js create .data/preview-store.json /مسار/خاص/نسخة.json
node scripts/backup.js restore /مسار/خاص/نسخة.json /مسار/خاص/ملف-مستعاد.json
```

الأداة تتحقق من مخطط المخزن والبصمة، وتنشر الملف الجديد حصريًا دون استبدال هدف موجود. الأصل يبقى. حد ملف النسخة64MiB؛ ما يزيد يُرفض صراحةً. صلاحية الملف0600. يتضمن السجل معلومات جلسات ومواد خاصة؛ احفظ النسخة في مكان خاص، ولا ترفعها للمستودع. البصمة تكشف التلف وليست توقيع مصادقة؛ استعد نسخة موثوقة فقط.

للاستعادة التشغيلية أوقف الخدمة، تحقّق من النسخة في وجهة جديدة، ثم اخترها عبر RAVEN_DIALOGUE_STORAGE_PATH وأعد التشغيل. لا دمج تلقائي بين تاريخين. مدة خمول الجلسة6ساعات تبقى مطبقة، وpending يستعادunknown دون نداء جديد. الأداة تخص ملف معاينة الحوار فقط؛ ليست نسخًا للدفتر المالي أو وعد حفظ سحابي أو ترحيلًا لقصة غير معتمدة. لا تغيير لقيمةstorage أو عقود المواد والمشاركات.
