# RAVEN — المجموعة البصرية الأولى

أربع صور أصلية مولّدة بالذكاء الاصطناعي، وفيلم مركّب منها مدته 24 ثانية بنسختين، وصفحة عربية لعرضها وتحميلها. تاريخ الإنتاج: 2026-11-06.

## المحتويات

| الملف | المحتوى |
| --- | --- |
| `assets/01-manor.png` | القصر تحت المطر |
| `assets/02-archive.png` | قاعة الأرشيف |
| `assets/03-desk.png` | المكتب وضوء المصباح |
| `assets/04-corridor.png` | الممر الحجري |
| `assets/*.webp` | نسخ خفيفة لعرض الصور على الويب |
| `media/raven-landscape.mp4` | فيديو أفقي 1920×1080، 24 إطارًا/ثانية |
| `media/raven-portrait.mp4` | فيديو عمودي 1080×1920، 24 إطارًا/ثانية |
| `media/poster-*.webp` | صورة معاينة لكل نسخة من الفيديو |
| `assets.json` | أوصاف الأصول ومصدرها وأحجامها وبصمات SHA-256 |
| `index.html`, `style.css`, `gallery.js` | صفحة العرض المستقلة |

## المشاهدة

داخل مشروع الاستوديو شغّل `npm run dev` ثم افتح `/visual-lab/index.html`، أو استخدم زر «مشاهد RAVEN والفيلم» في أعلى الاستوديو. المسار الصريح `index.html` يعمل أيضًا مع خادم Vite أثناء التطوير.

يمكن فتح `index.html` من الملفات مباشرة بعد فك الحزمة، أو تقديم المجلد بأي خادم ملفات ثابتة. لا تعتمد الصفحة على مفاتيح API أو خدمات خارجية. رابط العودة إلى الاستوديو يخص النسخة الموجودة داخل المشروع؛ وروابط الحزمة المضغوطة تخص النسخة المنشورة من الصفحة، فالملف المضغوط لا يتضمن نسخة من نفسه.

الفيديو لا يبدأ تلقائيًا؛ الصوت مغلق مبدئيًا ويمكن تفعيله. المشاهد تفتح في عارض يدعم لوحة المفاتيح: السهم الأيسر للتالي، والأيمن للسابق، وEsc للإغلاق. الصفحة تحترم إعداد تقليل الحركة وتعرض الصور الأصلية فقط عند فتح المشهد أو تحميله.

## إعادة إنتاج الفيديو

من جذر المستودع، بعد توفر FFmpeg وPython 3:

```sh
python -m pip install 'fonttools[woff]' brotli
python scripts/render-visual-lab.py
python scripts/package-visual-lab.py
```

السكربت يستخدم صور PNG الموجودة، ويُعيد تصدير نسخ WebP والفيديوهات وصور المعاينة فقط. لا يعيد توليد الصور بالذكاء الاصطناعي. يمكن اختيار مجلد الملفات الوسيطة باستخدام `--work-dir`. السكربت الثاني يحدّث بيانات الأصول وبصماتها وحزمة التحميل. السكربتان موجودان أيضًا داخل الحزمة للمحافظة على خطوات الإنتاج.

## مصدر الأصول وحدودها

الصور الأربع أُنتجت بأداة OpenAI الأصلية لتوليد الصور. دقة الملفات الأصلية 1672×941؛ إخراج الفيديو بدقة 1080p يتضمن إعادة تحجيم وقصًا مركزيًا للنسخة العمودية، ولا يعني أن الأصل مولّد بدقة 4K.

الفيديو مونتاج متحرك للصور الثابتة، بتقريب هادئ وانتقالات متداخلة وعنوان RAVEN. المطر والصوت المنخفض مؤثرات صوتية اصطناعية أُنشئت محليًا بواسطة FFmpeg؛ لم يُستخدم تسجيل بشري أو مسار موسيقي خارجي.

خطا Cinzel وIBM Plex Arabic من أصول RAVEN الموجودة في المستودع الآخر، للحفاظ على الهوية البصرية الحالية. الصور والمشاهد مقترحات فنية؛ لا تضيف أحداثًا أو معلومات للشخصيات، ولا تستبدل نص القصة الذي يُطوَّر في العمل الموازي. لم تُعدَّل ملفات القصة أو مواد معرفة الشخصيات لإنتاج هذه المجموعة.

الأدوات المستخدمة فعليًا: توليد الصور الأصلي، FFmpeg، أدوات المشروع، Chromium/Playwright. تعذّر استخدام 12ui لإنتاج التصميم لعدم اكتمال تسجيل الدخول. الصفحة مصممة محليًا، ولا تعتمد على اشتراك جديد أو تكامل غير متصل.
