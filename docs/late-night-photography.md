# Late Night photography and stage assets

The public WebP files in `raven/late-night/assets/photo/` are original, digitally generated production artwork for RAVEN’s fictional coastal town. They were generated for this project from written descriptions of the training spaces and then cropped, compressed or separated for use on the stage. A private story pack, actor reference or film frame was not used. The images serve locally from the same origin as the page.

| Files | Use in the production |
| --- | --- |
| `harbour-cinema.webp`, `harbour-cinema-mobile.webp` | Establishing view of the old cinema and harbour, used at the home entrance and in the Late Night programme. |
| The twenty files named for an activity in `catalog.js` | Individual programme stills. Activities use their location still in the working scene or accompany a technical diagram or script with the location. |
| `station-porter`, `auction-lots`, `lost-items`, `dome-disc` | A player figure, close-ups of the items offered or inspected, and the pierced-disc surface. |
| `reel-board`, `echo-chart` | A projection-room floor and harbour aerial provide the surfaces for the route and signal games. |
| `director-cinema`, `director-square`, `director-figure` | Alternative fictional locations and an actor for the local scene director. |
| `curtain-closed`, `scene-props`, `museum-base` | Closed drapery, movable foreground props and a clean exhibit plate for the interactive scenes. |

Small WebP prints in `raven/late-night/thumbs/` are derived from their corresponding activity plates for the programme grid. Artwork identifies locations and objects. The player determines movement, timing, order and lighting. The caption, controls and results are rendered as interface text in the selected language. The site displays the prepared assets without requesting an image-generation service during play.
