# بوابات الحوار المدفوع — مقفلة

هذه خطة تطوير وحالة تحقق، وليست عرض بيع أو أسعارًا معتمدة أو شروط شراء. لا توجد بوابة دفع حقيقية أو حسابات مشترين موثوقة أو استردادات مالية منفذة. لا يجعل الملف أدناه أو أي متغير بيئة الخدمة جاهزة للبيع.

## فصل الأنظمة

- افتتاح الموقع حوار مكتوب مجاني متاح؛ القضية الكاملة لم تُبنَ بعد، فلا نَعِد بأنها مكتملة الآن.
- server/ai-dialogue: جلسة مجهولة، ملف محلي واحد، مساعد مصادر اختياري. لا استحقاقات أو خصم مال أو endpoints شراء. controls.purchasesEnabled وentitlementUseEnabled ثابتان false.
- server/src: محاكي رصيد محلي مستقل. تشغيل مساراته يحتاج RAVEN_ENABLE_CREDIT_SIMULATION=1. يرفض إعداد مزوّد غير simulation، ويرتبط بـ127.0.0.1. لا تعرّضه عبر وكيل عام؛ loopback ليس مصادقة للمستخدم.
- RAVEN_MODEL_CALLS_ENABLED=0 أو ملف تحكم خاص يوقف النداءات الخارجية الجديدة، ويبقي القراءة والحوار المكتوب. لا يدّعي إلغاء نداء سبق أن بدأ.

## معايير البيع وحالتها

| المعيار | الحالة الفعلية |
|---|---|
| القضية الأساسية قابلة للإكمال مجانًا | يحتاج محتوى: الافتتاح فقط متاح؛ لا حجب دليل معتمد وراء رصيد |
| محتوى شخصية مدفوعة معتمد وتجربة نموذج حي | غير جاهز؛ المساعد الحالي يختار مواد وصلته ولا يؤلف إفادة |
| حساب مستخدم وصلاحيات مالية | غير موجود؛ الكوكي المجهول ليس حساب مشتري |
| حفظ واستعادة | اختبار ملف الحوار المحلي متاح؛ ليس قاعدة مالية موزعة أو ضمان استعادة كل شراء |
| عرض سعر محفوظ ومنح مرة واحدة | اختُبر في المحاكي فقط؛ لا بوابة حقيقية |
| إعادة الطلب دون خصم ثانٍ | اختُبرت في محاكي SQLite؛ لا ضمان تنفيذ مزوّد خارجي مرة واحدة |
| استرداد وتسوية مالية ومطابقة بوابة | غير منفذة؛ لا نقبل المال قبلها |
| شروط وخصوصية ودعم وبلد نشاط | تحتاج قرارات المالك ومراجعة مناسبة؛ لا عنوان دعم أو مدة استجابة مخترعة |
| حصص حسابات وإنفاق ومراقبة | مفتاح إيقاف موجود؛ حدود الإنفاق المالية والمراقبة الدائمة غير منفذة |
| موافقة إطلاق وتجربة محدودة | غير موجودة؛ لم يُطلب أو يُنفذ شراء حي |

## تعريف الاستحقاق قبل اختيار سعر

يحتاج الاعتماد: دور حوار كامل أم طلب؟ حدود الطلب والرد، احتساب رفض المحتوى، صلاحية الاستحقاق، التوقف والاسترداد. لا «غير محدود»، ولا ادعاء أن الدفع يضمن الاعتراف أو دقة أعلى. أخطاء المشروع وإعادة المحاولة الداخلية لا تُحمّل اللاعب تلقائيًا. مفاتيح اللاعبين BYOK مؤجلة، وليست خيارًا منشورًا.

هدف 50% للتشغيل داخلي، وليس ربحًا مضمونًا. عرّف أولًا N = المقبوضات دون الضرائب المحصلة للغير، ناقص الرسوم والاستردادات والنزاعات وصرف العملة. ميزانية النموذج المستهدفة = 0.5×N. المتبقي بعد النموذج يُخصم منه الاستضافة والدعم والاحتياطي وبقية التكاليف؛ ليس ربحًا صافيًا تلقائيًا. القياسات المطلوبة قبل تسعير باقة: استهلاك فعلي وسيط وP95 للطلب والرد والسياق، نسبة الأعطال وإعادة المحاولات، رسوم البوابة الفعلية وبلدان البيع. لم أضع سعر بيع أو نسبة ضريبة أو بوابة باسم المالك.

## عقد مالي لاحق، غير منفذ الآن

عرض السعر الخادمي يثبت المبلغ والعملة والاستحقاق وإصدار الشروط والحساب المستفيد. إشعار البوابة الموثق، لا صفحة النجاح، يفتح معاملة قاعدة بيانات تمنح مرة واحدة. الإشعارات المكررة والمتأخرة وخارجة الترتيب تحتاج سجلًا دائمًا مستقلًا عن سجل عرض المحادثة وتسوية دورية مع البوابة.

طلب الحوار المدفوع: معرف ثابت مربوط بحساب موثوق وإصدار سياق؛ حجز الاستحقاق قبل العمل، ثم تسوية عند نتيجة معروفة. timeout وإغلاق المتصفح لا يعنيان فشل المزود أو الإلغاء. الحالة unknown تُراجع دون خصم ثانٍ أو وعد باسترداد خارجي تلقائي. يُحفظ الرد قبل اعتماد استهلاك الاستحقاق وفق السياسة المتفق عليها.

الاسترداد عملية مالية مسجلة idempotent، لا تعديل رقم الرصيد فقط. يُحفظ تقدم القضية، ويعرف اللاعب رقم الطلب وما يعاد جزئيًا أو كليًا. بلد الكيان وبلدان البيع والبوابة والدعم وسياسة الاحتفاظ قرارات باقية؛ لم نفترضها من لغة المالك.

## مصفوفة القبول

| السيناريو | طبقة التحقق الحالية |
|---|---|
| نقرتا شراء / نفس المعرف | محاكي محلي؛ replay أو409 عند اختلاف المشتري/الباقة |
| توقيع مزور / جسم متغير | محاكي HMAC؛ ليس قبول توثيق بوابة إنتاج |
| إشعار مكرر / مبلغ أوعملة مختلفان | محاكي فقط؛ منح واحد والتحقق قبل replay |
| تغيّر الباقة بعد إنشاء الطلب | المحاكي يحتفظ بعدد الاستحقاقات في quote |
| طلبان على آخر استحقاق | محاكي SQLite؛ لا سحب تحت الصفر |
| فشل حفظ رد المحاكي | transaction تتراجع عن الخصم والتقدم |
| إعادة تشغيل خادم الحوار / نتيجة معلومة وحفظ غير مؤكد | Node/HTTP ومتصفح محلي، لا حساب مشتري |
| نسخة احتياطية تالفة / استعادة إلى ملف موجود | مرفوضة؛ الأصل يبقى |
| إشعار قبل رجوع المتصفح أو خارج الترتيب / انقطاع DB بعد دفع حي | BLOCKED: بوابة تجريبية ومخطط مالي غير موجودين |
| قراءة عملية مشترٍ آخر | BLOCKED ماليًا؛ عزل كوكي معاينة الحوار مختبر فقط |
| استرداد مكرر/جزئي/كامل وتسوية | BLOCKED: لا بوابة استرداد |
| استعادة دفتر مالي دون منح ثانٍ | BLOCKED: أداة النسخ الحالية تخص الحوار، لا دفتر مشتريات |
| ترحيل تقدم قصة بين إصدارين | لا حفظ تقدم قصة حاليًا؛ دفتر القراءة محلي بإصدار معلوم، لا استيراد يعيد تفسيره |

لا يتحول BLOCKED إلى PASS لمجرد وجود خوارزمية أو صفحة نجاح. ترتيب الإطلاق: محتوى مكتوب واختبار جمهور، ثم حساب وحفظ ودورة عمليات، ثم نموذج محدود بلا بيع، ثم بوابة تجريبية وتسوية/استرداد، ثم موافقة بيع محدود.
