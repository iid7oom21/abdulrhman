## تحديث خطة المراجعة — 2026-11-05 (لا نشر ولا دفع)

النص التاريخي الذي يصف RAM فقط يخص النسخة السابقة، ولا يصف التعديل البرمجي الحالي في فرع الخادم. PR101 أتاح ملفًا اختياريًا؛ التعديل الحالي يجعل CLI يستخدم `.data/preview-store.json` افتراضيًا، أو `RAVEN_DIALOGUE_STORAGE_PATH`. ربط القرص وحده لم يكن يكفي؛ كود الحفظ منفصل عن توفير قرص الاستضافة، ويُختبر على فرع `main`.

التقدير الذي قدمه المالك: Web Service Starter نحو $7/mo وPersistent Disk 1GB نحو $0.25/mo. لم تُراجع الأسعار الحية ولم تُنشأ خدمة أو تُدفع رسوم. راجع السعر عند اعتماد النشر.

إعداد Render المقترح: فرع `main` بعد مراجعة PR، Root Directory `server/ai-dialogue`، Start Command `node src/server.js`، Health Check `/healthz`، وNode 24.
اربط القرص عند `/var/data`، واضبط `RAVEN_DIALOGUE_STORAGE_PATH=/var/data/preview-store.json` و`HOST=0.0.0.0` و`RAVEN_COOKIE_SECURE=1`. المنفذ من `PORT` الذي تضبطه المنصة. استخدم عملية واحدة دون عمال متعددين على الملف.
ابدأ بـ`RAVEN_AI_PROVIDER=simulation`. تفعيل OpenAI يحتاج مفتاحًا في إعدادات الخدمة، واختبار وصول وحصص مستخدمين قبل فتحه للعامة؛ كوكي جلسة مجهولة ليس حسابًا. لا تنقل المفتاح إلى HTML ولا تربط GitHub Pages في هذه الجولة.

يبقى بعد إعادة التشغيل ما دام القرص نفسه موجودًا. يضيع إذا مُسح القرص أو تغيّرت الآلة. هذا ليس حفظ إنتاج سحابي. حدود خمول الجلسة وسعتها تبقى مطبقة.
قبول النشر لاحقًا: نفس الكوكي بعد restart يعيد الطلب والمواد؛ نفس المعرف يعاد دون توليد، وتغيير المحتوى 409، والنسخة التالفة لا تُستبدل. وجود القرص وحده لا يثبت قبول هذه الشروط.
