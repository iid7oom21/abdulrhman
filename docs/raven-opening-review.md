### إعادة التشغيل

تحتاج بيئة تحتوي Node وPlaywright وChromium. من جذر المستودع:

```sh
CHROMIUM_PATH=/usr/bin/chromium node --test tests/opening-hook.mjs
node tests/restore-episode-one.mjs
```

الاختبار الأول ينشئ خادم ملفات محليًا مؤقتًا بنفسه. لتشغيل فحوص غلاف الموقع، شغّل في طرفية منفصلة:

```sh
python3 -m http.server 8768 --bind 127.0.0.1
```

```sh
CHROMIUM_PATH=/usr/bin/chromium PLAYWRIGHT_TEST_MODULE=playwright RAVEN_REDESIGN_URL=http://127.0.0.1:8768/ node tests/deleted-name.mjs
```
