# القضية المكتوبة — تشغيل خاص

محرك القضية مستقل عن محاكاة الحوار وعن النموذج الاختياري. يعرض المشاهد المكتوبة حسب تقدم اللاعب، ويحتفظ بالدفتر والتقارير والإيصالات داخل القصة. لا يرسل تقريرًا إلى جهة حقيقية ولا يستدعي نموذجًا. حزمة القصة الخاصة لا تُرفع إلى هذا المستودع أو إلى GitHub Pages.

يلزم Node.js 24، ونسخة ملفات الموقع من فرع `gh-pages` تتضمن `raven/deleted-name/play/`، وحزمة القصة الخاصة خارج مجلدي Git والموقع. لا يلزم `npm install` لتشغيل الخادم. اختُبر التشغيل على Linux؛ الحفظ يستعمل خصائص ملفات POSIX، ولا ندّعي اختبار Windows.

```bash
node server/ai-dialogue/scripts/start-case.mjs --content /absolute/private/raven-case-content.json --site /absolute/public-site --data /absolute/private/saves
```

افتح الرابط الذي يظهر. يبدأ الخادم على هذا الجهاز فقط؛ لا ينشر خدمة على الإنترنت. صفحة القضية تحت `/raven/deleted-name/`، والمتابعة تحت `/raven/deleted-name/play/`. حافظ على مجلد الحفظ، وافتح من المتصفح نفسه للاحتفاظ بكوكي الجلسة. نقل ملفات الحفظ وحده لا يستعيد جلسة في متصفح جديد؛ تنزيل سجل القضية نسخة قراءة وليس استيرادًا منفذًا.

بعد نهاية الافتتاح يظهر زر المتابعة إذا كانت حزمة القصة متاحة. ينقل اختيار الافتتاح المحدد فقط بعد مراجعة اللاعب، ولا ينقل دفتره المحلي أو ملاحظاته تلقائيًا. الجلسة القائمة تُستأنف دون إعادة تطبيق الافتتاح.

## إعداد خادم مخصص

يمكن للتشغيل العادي استخدام `RAVEN_SITE_ROOT` و`RAVEN_CASE_CONTENT_PATH` و`RAVEN_CASE_STORAGE_PATH`. ملف القصة خارج Git والجذر العام شرط يتحقق منه الخادم. لا توضع أسرار المؤلف في حزمة JavaScript، ولا تُرسل مشاهد لم يفتحها اللاعب. مسارات `/api/case/*` منفصلة عن `/api/dialogue`، وحفظها وكوكيها منفصلان.

الإعداد المحلي ذو ملف واحد ومشغّل واحد، وليس خدمة موزعة أو حفظ حسابات سحابيًا. لن تُشغّل GitHub Pages هذا الخادم. إتاحة القصة على رابط عام تحتاج استضافة Node وHTTPS ومساحة حفظ دائمة وإدارة نسخ احتياطية وحدود طلبات مناسبة؛ لا ينجز رفع المصدر ذلك تلقائيًا.

## استعادة وفحص

أوقف الخادم قبل نسخ مجلد الحفظ، واحتفظ بنسخة من حزمة المحتوى بالإصدار نفسه. يُرفض الملف التالف دون استبداله بملف فارغ. عند فشل تأكيد الكتابة يتوقف تقدم الجلسة حتى الاستعادة؛ لا يُعرض ذلك كحفظ ناجح. تغيير إصدار القصة يجعل الجلسات الأقدم للقراءة والتنزيل حتى إتاحة إصدارها، ولا يعيد تفسير اختياراتها.

شغّل عاملًا واحدًا لكل مجلد حفظ. يمنع المخزن كاتبًا ثانيًا من استبدال نسخة تغيّرت منذ قراءتها، ويستخدم قفلًا قصيرًا أثناء الكتابة. إذا انقطع التشغيل وترك `case-store.json.lock`، لا تحذفه والخادم يعمل: أوقف جميع العمليات التي تستخدم المجلد، وانسخ ملف الحفظ والقفل، وافحص النسخة، ثم أزل القفل المتروك وأعد تشغيل عامل واحد. لا يستولي البرنامج على قفل بناءً على عمره أو رقم عملية قديم.

الاختبارات في المستودع تستخدم قصة خيالية مصغرة. فحص مسارات القصة الخاصة ينتج تقريرًا خارج Git، فلا يكشف الاختبار الحل للقارئ العام.
