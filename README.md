# RAVEN — دليل مسارات المشروع

الموقع وقضية «الاسم المحذوف» وخادم الحوار لها مسارات مختلفة. هذا الدليل يحدد ما تشغله الأوامر؛ لا يستبدل أصولًا أو قصصًا.

| المسار | ما يشغّله | الأمر / الفرع |
|---|---|---|
| `server/ai-dialogue` | معاينة الحوار، جلسات ومواد ومشاركة، حفظ ملف، وربط OpenAI اختياري | `npm start` من الجذر، المنفذ 10000 |
| `src/` | استوديو RAVEN: الفيلم المدمج، الصور الأربع، مكتبة المشاهد ومسودات الجلسة؛ دون توليد فيديو مباشر | `npm run dev`، المنفذ 3000 |
| `raven/` في `gh-pages` | الموقع المنشور وافتتاح القضية والموسيقى والحلقات | موقع ساكن مستقل |
| `raven/dialogue/` في `gh-pages` | محاكاة متصفح مستقلة، غير موصولة بخادم الحوار | GitHub Pages |
| `server/src/` | محاكي رصيد محلي مقفل افتراضيًا؛ لا دفع حقيقي أو حسابات موثوقة | [تشغيل اختباري فقط](server/README.md) |
| `review/` و`docs/` | مراجع وتسليمات تاريخية | ليست مصدر معرفة الشخصيات |

ابدأ الحوار بـ `npm start` وافتح `http://127.0.0.1:10000`. لا حاجة إلى مفتاح أو رصيد في وضع المحاكاة الافتراضي.
لربط OpenAI اقرأ [دليل الحوار](server/ai-dialogue/README.md). لا تضع مفتاحًا في HTML أو Git أو المحادثة.
اختبارات المنطق وHTTP: `npm test`. اختبارات المتصفح: `CHROMIUM_PATH=/usr/bin/chromium npm run test:browser` (تحتاج Playwright).
بناء نموذج الاستوديو منفصل: `npm ci --ignore-scripts` ثم `npm run build`.

لا تنقل شجرة `main` إلى `gh-pages` أو العكس. افحص رؤوس الفرعين وأنشئ فرعًا لكل تغيير. النسخة المنشورة لا تصبح موصولة بمجرد رفع كود الخادم.


## المشاهد والفيلم المدمجان

تفتح واجهة الاستوديو على فيلم RAVEN الفعلي. تظهر الصور الأربع تحت المشغّل؛ اختيار صورة ينتقل إلى موضعها في الفيلم دون مغادرة الصفحة. يمكن تبديل النسخة الأفقية والعمودية مع الاحتفاظ بموضع التشغيل وحالته. توفر «مكتبة الصور» بحثًا عربيًا وإنجليزيًا وتحميل وصف اللقطة داخل إعدادات المشروع.

الأصول محفوظة محليًا في `public/visual-lab` وتُستخدم مباشرة من مكوّنات React، بلا حاجة إلى صفحة المعرض أو تحميل حزمة. مسودات الاستوديو مؤقتة للجلسة؛ لا يعيد زر إضافة المسودة تقديم فيلم موجود على أنه توليد جديد. القصة ومواد معرفة الشخصيات لم تتغير.

### نشر الاستوديو ضمن الموقع

يبنى الاستوديو لمساره العام باستخدام `npm run build -- --base=/abdulrhman/studio/`. تُنسخ `dist/index.html` و`dist/assets/` و`dist/visual-lab/` فقط إلى `studio/` في فرع نشر مبني على أحدث `gh-pages`. لا تُنسخ `dist/raven/`؛ موقع القصة الموجود في فرع النشر هو المصدر المعتمد. مسارات الفيديو والصور وخط الواجهة تتبع مسار البناء، وزر الأرشيف يعيد الزائر إلى موقع RAVEN الأصلي.
