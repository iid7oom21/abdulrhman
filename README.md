# RAVEN — دليل مسارات المشروع

الموقع وقضية «الاسم المحذوف» وخادم الحوار لها مسارات مختلفة. هذا الدليل يحدد ما تشغله الأوامر؛ لا يستبدل أصولًا أو قصصًا.

| المسار | ما يشغّله | الأمر / الفرع |
|---|---|---|
| `server/ai-dialogue` | معاينة الحوار، جلسات ومواد ومشاركة، حفظ ملف، وربط OpenAI اختياري | `npm start` من الجذر، المنفذ 10000 |
| `src/` | نموذج واجهة استوديو فيديو ببيانات تجريبية، دون توليد فيديو حقيقي | `npm run dev`، المنفذ 3000 |
| `raven/` في `gh-pages` | الموقع المنشور وافتتاح القضية والموسيقى والحلقات | موقع ساكن مستقل |
| `raven/dialogue/` في `gh-pages` | محاكاة متصفح مستقلة، غير موصولة بخادم الحوار | GitHub Pages |
| `server/src/` | نموذج قديم لمحاكاة الرصيد والدفع | مستقل؛ لا تحتاجه القضية الأساسية |
| `review/` و`docs/` | مراجع وتسليمات تاريخية | ليست مصدر معرفة الشخصيات |

ابدأ الحوار بـ `npm start` وافتح `http://127.0.0.1:10000`. لا حاجة إلى مفتاح أو رصيد في وضع المحاكاة الافتراضي.
لربط OpenAI اقرأ [دليل الحوار](server/ai-dialogue/README.md). لا تضع مفتاحًا في HTML أو Git أو المحادثة.
اختبارات المنطق وHTTP: `npm test`. اختبارات المتصفح: `CHROMIUM_PATH=/usr/bin/chromium npm run test:browser` (تحتاج Playwright).
بناء نموذج الاستوديو منفصل: `npm ci --ignore-scripts` ثم `npm run build`.

لا تنقل شجرة `main` إلى `gh-pages` أو العكس. افحص رؤوس الفرعين وأنشئ فرعًا لكل تغيير. النسخة المنشورة لا تصبح موصولة بمجرد رفع كود الخادم.
