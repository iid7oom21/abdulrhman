🧪 Add tests for Header component

🎯 **What:** The Header component previously lacked test coverage.
This change sets up the necessary vitest/testing-library test environment
and adds a suite of tests for the Header component.

📊 **Coverage:**
- Rendering of titles and descriptions (both English and Arabic paths)
- Tab clicking handling (`setCurrentTab`)
- Model selection change handling (`setActiveModel`)
- The code snippet button handling (`onOpenCode`)
- Language switching (`setLang`)

✨ **Result:** The test coverage for the core `Header` UI functionality is now present, ensuring interactions like changing tabs and language remain functional as the application scales.
